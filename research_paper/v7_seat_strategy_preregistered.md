# v7 — seat-specific strategy: preregistration

Written 2026-10-19, after the exploratory screen below and before any confirmation game. Results go in
`v7_seat_strategy_results.md`. This file is not edited after the confirmation starts, except to
append dated addendum entries at the end.

## Why

The goal is to maximise win rate by letting each starting position play differently. A
`v4.2-ultra` mirror (800 seeds from 74,200,000; `ml/seat/results/`) shows how much turn order
matters. The turn order is blue, green, purple, yellow:

| Seat | Win share |
|---|---:|
| blue (1st) | 27.4% |
| green (2nd) | 33.5% |
| purple (3rd) | 24.5% |
| yellow (4th) | 14.7% |

Earlier work found that hand-set per-seat *weight constants* were noise (v4 report §5: −0.10
[−0.36, 0.16]).

## Exploratory screen (measured before this document; not evidence)

Six single-knob variants of `v4.2-ultra` were each played against `v4.2-ultra` on 400 seeds from
74,200,000.

- **Read per seat.** In a seat-rotated match the challenger occupies one seat per game, so each
  seat's games measure the variant *as played from that seat*.
- **Baseline.** Each variant is compared with the mirror on the same seeds, using a paired
  bootstrap over seeds.

Δ win share, in percentage points:

| Variant | blue | green | purple | yellow |
|---|---|---|---|---|
| `rankBlend` 0 | +0.7 | −3.0 | +0.8 | +0.2 |
| `rankBlend` 0.7 | −0.5 | −1.6 | −2.7 | +0.5 |
| `rankBlend` 1.0 | +4.0 | +1.0 | −0.9 | −0.9 |
| seat profile flat (all 1) | −0.7 | −2.8 | −1.4 | +3.6 [−0.9, 8.0] |
| `aggressionScale` 1.4 | **+7.2 [1.2, 13.4]** | −1.4 | +1.3 | −0.7 |
| `aggressionScale` 0.6 | +2.1 | −5.7 | −2.2 | −3.3 |

There are 24 cells here, so roughly one false positive is expected at the 5% level. The two
largest seat-specific candidates were selected for confirmation:

- **H1:** `agg140` played from **blue** (the first seat).
- **H2:** `flat` played from **yellow** (the last seat).

Green is to be left at `v4.2-ultra`, since every change measured so far, E4 included, lowered
green's advantage.

## Confirmation

- **Seeds:** 1,600, from 75,000,000 to 75,001,599. This block is disjoint from every earlier block.
- **Budget:** 300 base iterations, native engine.
- **Runs:**
  1. a `v4.2-ultra` mirror (per-seat baseline);
  2. `agg140` against `v4.2-ultra`;
  3. `flat` against `v4.2-ultra`.

  Configs are `ml/data/seat/configs/{agg140,flat}.json`, generated by `ml/seat/mkvariants.py`.
- **Metric:** win share in the target seat: 1/k when tied with k − 1 others for first, else 0.
  It is computed by `ml/seat/seat_report.py` as the variant minus the mirror on the same seeds,
  with a paired bootstrap 95% CI over seeds.
- **H1 passes** if blue's Δ win share has its CI lower bound above 0.
- **H2 passes** if yellow's Δ win share has its CI lower bound above 0.
- Each hypothesis is read on its own; no correction across the two.
- **Secondary, reported but not gated:**
  - the same Δ in advantage;
  - the variant's Δ in the other three seats.
- **Power:** the screen's per-seat SE was about 3 pp at 400 seeds, so it should be about 1.5 pp
  at 1,600. The minimum detectable effect at 80% power is about 4.3 pp:
  - H1's screen estimate (+7.2) clears that, even allowing for some shrinkage.
  - **H2 is likely underpowered.** A null there means "not shown", not "no effect".

## What a pass leads to

A configuration that plays `agg140` from blue, `flat` from yellow, and `v4.2-ultra` elsewhere,
using only the hypotheses that pass.

- **Its per-seat behaviour is already known.** It is the same as the confirmed per-seat runs,
  because the challenger's seat decides which config it plays.
- **To ship it,** the native engine needs root-seat dispatch, which picks a full parameter set by
  the searching seat. It must be byte-identical when unused: a `cargo test` parity check and a
  0.00 mirror.
- **Promotion** then requires the dispatch config to beat `v4.2-ultra` on overall win share, with
  the CI lower bound above 25%, on a fresh block fixed in an addendum before it runs.

## Not claimed

- Engine opponents only. No claim about humans.
- `rankBlend` 1 for the last seat ("gamble for the win") is not pursued. The screen gave it
  −0.9 pp in yellow, and it may be revisited with a true P(first) utility, which the engine does
  not have.
