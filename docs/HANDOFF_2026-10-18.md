### 4. Seat-specific strategy: designed, screen paused before any variant finished
- **Goal (from Paul):** different strategies for different starting positions, to maximise win
  rate. The last mover should play differently from the first.
- **Prior work, read before designing this** (`blokus_ai_research_report_v4.md` §5):
  - Hand-set per-seat *weight constants* measured −0.10 [−0.36, 0.16], which is noise.
  - Dropping 20 seat multipliers from a 66-parameter tuning fit cost nothing.
  - `v4.2-ultra` still carries such a hand-set profile (`seats`: yellow aggression 1.25 against
    blue 0.8, and so on).
  - What has **not** been tried is changing *what each seat optimizes*, as opposed to how it
    weighs evaluation terms.
- **Levers in the engine:**
  - `search.rankBlend` (0.35) mixes score margin with placement in the backed-up utility:
    `(1−β)·sigmoid(margin/12) + β·fraction-of-opponents-beaten`. `objectiveShift` halves β when
    leading and raises it toward 1 when behind. See `engine-rs/src/backup.rs` and `search.rs:247`.
  - `aggressionScale` scales blocking.
  - `seats[s]` multiplies evaluation terms for seat s.
- **Measurement trick:** in a seat-rotated match the challenger occupies one seat per game, so one
  variant config gives a separate effect estimate for each seat. Each variant is compared with the
  mirror on the same seeds; `ml/seat/seat_report.py` does the paired per-seat bootstrap.
- **Exploratory screen** (`ml/seat/screen.sh`, not preregistered): 6 variants × 400 seeds from
  74,200,000, each against `v4.2-ultra`.

  | Variant | Change |
  |---|---|
  | `rb0` | `rankBlend` 0 |
  | `rb70` | `rankBlend` 0.7 |

  | `flat` | all seat multipliers 1 |
  | `agg140` | `aggressionScale` 1.4 |
  | `agg60` | `aggressionScale` 0.6 |

## Gotchas found today
- The `wsl` + Git Bash quoting is fragile. Put scripts in a file and run them with
  `wsl -d Ubuntu -- bash <file>`, using `MSYS_NO_PATHCONV=1`.
- Ubuntu 26.04 ships uutils coreutils, and its `tr` has no `-u`.
- `pkill -f <pattern>` inside `bash -c '...'` also matches its own command line.
- `blokee-match` has no `--help`. Read the flags in `engine-rs/src/bin/blokee-match.rs`.
